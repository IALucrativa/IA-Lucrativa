# Regras do projeto

## Vídeos
- **Duração obrigatória: no mínimo 1 minuto (60 s) e no máximo 2 minutos (120 s).** Vale para todos os vídeos.
- Os vídeos ficam em `videos/<nome-do-video>/`, cada um com `scene.html`, `render.js`, `sfx.py` e `ROTEIRO.md`.
- O `render.js` se recusa a renderizar se `DURATION` estiver fora desse intervalo.
