# Respostas e contagem de soldados

Só é usado se você pedir para o Claude contar os soldados.
Um arquivo por desafio: `AAAA-MM-DD_<série>-dNN.md` (data da Convocação), com a tabela plataforma · @ · comentário · tipo e, no fim, o total de cada plataforma por tipo.
O total é só para você: nunca vai para a resposta pública. É ele que você leva para a pasta `Vídeos Batalha` montar a Batalha.
